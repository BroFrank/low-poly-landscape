# Low Poly Landscape

Веб-приложение для ландшафтного дизайна в low-poly стиле на **three.js**: редактирование рельефа,
кисти покрытий, расстановка объектов, свободная камера, день/ночь, скриншоты и сохранение сцены.

## Быстрый старт

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка TypeScript и production-сборка
npm run preview  # запуск собранной версии
```

## Управление

| Действие | Как |
|---|---|
| Движение камеры | ЛКМ — вращение, колесо — зум, WASD — панорама, `Q`/`E` — вверх/вниз, `R` — сброс вида |
| Подъём / опускание рельефа | Инструмент «Высота» + ЛКМ (удерживать), `Shift`+ЛКМ — опускать |
| Радиус и сила кисти | Слайдеры в панели инструментов |
| Каменистый / земляной участок | Кисти «Камень» и «Земля» |
| Объекты | Панель объектов → выбрать тип → клик по ландшафту |
| Выделить / переместить / удалить | Клик по объекту → перетащить / стрелки → `Delete` |
| Скриншот | Кнопка «Скриншот» или `S` |
| День / ночь | Кнопка или `D` (auto-cycle — плавный цикл) |
| Сброс | Кнопка «Сброс» |
| Сохранение | `Ctrl+S`, автосохранение в localStorage |

## Мульти-агентская разработка

Проект разработан в режиме оркестрации OpenCode: задачи берутся из `Plan.md` и проходят цикл
`оркестратор → планировщик → имплементатор → ревьюер → ручная проверка юзера → коммит`.

```
          ┌────────────┐
          │ orchestrator│  (primary)
          └──┬──────┬──┘
   план задачи│      │ дифф
             ▼      ▼
          planner  reviewer
             │      │
             ▼      │ замечания P0/P1
        implementer ◄┘
             │
             ▼
      отчёт + шаги проверки ──► юзер подтверждает?
                                ├─ да  → статус [x] + git commit
                                └─ нет → цикл planner → implementer → reviewer
```

### Команды для агента

| Команда | Что делает |
|---|---|
| `/next_work` | Оркестратор берёт **первую незакрытую** задачу из `Plan.md` и ведёт её до подтверждения юзером |
| `/work T008` | Выполнить конкретную задачу по ID |
| `/status` | Прогресс: выполнено / в работе / следующая задача, что блокирует |
| `/fix T008 не работает кисть` | Цикл фикса: план фикса → реализация → ревью → повторная проверка |
| `/plan <текст>` | Встроенная команда OpenCode: быстрый план без реализации |

Агенты:

| Агент | Режим | Роль |
|---|---|---|
| `orchestrator` | primary | Ведёт цикл, меняет статусы `Plan.md`, коммитит |
| `planner` | subagent | Подробный технический план / план фикса |
| `implementer` | subagent | Код по плану |
| `reviewer` | subagent | Самопроверка диффа перед ручной проверкой |

Конфигурация: `opencode.jsonc`, `.opencode/agents/*`, `.opencode/commands/*`.

### Статусы задач в `Plan.md`

```
- [ ]  не начато
- [~]  в работе
- [x]  выполнено и подтверждено юзером
```

Задача закрывается **только после подтверждения юзера** — агент не отмечает её выполненной сам.

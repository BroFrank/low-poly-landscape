agent: plan

Проанализируй `Plan.md` и выведи:

!`grep -nE "^### - \[[ ~x]\] \*\*T[0-9]{3}" Plan.md`

Формат ответа:

```
Выполнено: N / 21
В работе:  TNNN — название
Следующая: TNNN — название
Блокирует: <если есть зависимости, которые ещё не закрыты>
```

Ничего не меняй в файлах.
